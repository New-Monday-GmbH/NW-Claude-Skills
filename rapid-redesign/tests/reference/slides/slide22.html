Inspiration 01 · linear.app

Inspiration

Ruhe als Botschaft

Linear verkauft ein komplexes Produkt mit fast leeren Flächen. Jede Sektion trägt genau einen Gedanken — der Blick weiß immer, wo er hin soll.

  • Ein Satz, ein CTA, ein Visual. Sonst nichts.
  • Features als Produktansicht statt als Icon-Kachel.
  • Kontraststarke Typo trägt die Aussage allein.
